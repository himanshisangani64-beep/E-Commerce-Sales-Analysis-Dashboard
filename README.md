## 📌 Project Overview

This project uses **Microsoft Excel** to process and analyze e-commerce order data and create an interactive sales reporting dashboard.

The **E-Commerce Sales Analysis Dashboard** helps analyze sales performance, profitability, customer segments, product categories, brand costs, order fulfillment, and regional trends.

It combines KPI cards, charts, summary tables, and interactive slicers to transform raw transactional data into meaningful business insights.

## 🎯 Project Objective

- Monitor key business KPIs, including total orders, customer count, average profit, and average sales.
- Evaluate sales performance across Electronics, Fashion, and Sports categories.
- Identify top-performing products based on sales contribution.
- Analyze customer segments, including Consumer, Corporate, and Home Office.
- Compare cost distribution among leading brands.
- Monitor order statuses such as Delivered, Shipped, Returned, and Cancelled.
- Compare sales performance across cities and regions.
- Explore sales trends across different months and years.
- Build an interactive Excel dashboard for e-commerce sales reporting and analysis.

## 🔄 Workflow: From Data to Insights

This project follows a structured workflow to transform e-commerce transactions into meaningful business insights.

| **Step** | **Phase** | **Description** |
|---|---|---|
| 01 | Raw Data Processing | Clean and organize e-commerce transactions and customer details. |
| 02 | KPI Calculation | Calculate sales, profit, customer count, order counts, and average metrics. |
| 03 | Data Summarization | Use PivotTables to summarize sales by segment, city, category, brand, and order status. |
| 04 | Data Visualization | Create doughnut, bar, pie, and column charts. |
| 05 | Dashboard Assembly | Integrate interactive slicers for year, region, and month. |
| 06 | Insight Extraction | Identify top products, brand cost patterns, customer segments, and order fulfillment trends. |
